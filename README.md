# Neverhash

Neverhash is a writing and repository-organization skill for AI agents. It helps an unfamiliar reader understand a project without searching through repeated documents, incidental details, or machine-specific artifacts.

## Use

Read [SKILL.md](SKILL.md) for the complete policy. Apply it when an agent writes documentation, reorganizes a repository, prepares a pull request, or decides which files belong in a commit.

Example instruction:

> Apply Neverhash to this repository. Make the README useful to a first-time reader, consolidate overlapping documents, and review proposed files for permanent value. Preserve necessary facts and reproducible instructions.

## Design

Neverhash adapts the direct language of [ASD-STE100 Skill](https://github.com/danyuchn/asd-ste100-skill), which uses Simplified Technical English principles to reduce ambiguity in agent-facing text. Neverhash also governs what to say, where to say it, and what to commit. It is an independent style policy, not an official ASD-STE100 implementation.
